# REDCap Excel File Converter

REDCap frequently exports Excel files in which baseline and follow-up scores are positioned in rows directly beneath patient demographic data. While this structure can be manually adjusted for small datasets, it becomes inefficient and error-prone when managing large cohorts with extensive longitudinal follow-up.

To address this limitation, this application provides a web-based solution with backend processing that automatically identifies baseline and follow-up score fields and reorganizes them into the appropriate format. The converter supports up to 50 years of follow-up data, significantly reducing manual effort and improving data consistency.
